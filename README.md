# Exercício módulo 32 — Consulta de produtos

Filtra produtos acima de R$ 100, ordena a lista por nome e permite buscar um produto sem diferenciar maiúsculas e minúsculas.

## Conceitos praticados

Stream API, Comparator e tratamento de resultado com Optional.

## Como executar

1. Abra a pasta do projeto no IntelliJ IDEA.
2. Configure um JDK 17 ou superior.
3. Execute o método main da classe Main.
